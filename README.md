A tiny program that writes one funny line to a text file. The line is 63
characters: a tax return comes back with a note that just says "nice try."
The program checks the line before writing it, so the file stays inside
the 200-character limit, and it writes plain UTF-8 text with no trailing
newline, exactly one line.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). See the entry on
[make.fun](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae).
